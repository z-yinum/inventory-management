Global Filter System

Four filters in useFilters.js apply globally across all views and API calls. Each maps to a query param on the backend.

Time Period
?month=
all • YYYY-MM • Q1-2025 through Q4-2025
Quarter maps to 3 month values
Warehouse
?warehouse=
all • San Francisco • London • Tokyo
Category
?category=
all • Circuit Boards • Sensors • Fasteners • Filters • Springs
Order Status
?status=
all • Delivered • Shipped • Processing • Backordered
Orders view only
Note: Inventory filters don't support the month param (no time dimension on stock data). Dashboard summary supports all four filters simultaneously.
